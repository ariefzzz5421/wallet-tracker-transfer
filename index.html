About formats & group preservation +

Notion paste accepts copied table rows (TSV/CSV), including GuarEmperor-style tables such as Rank / Wallet / Explorer / OpenSea / Tag. Wallet is detected as the address column and Tag is preserved as group metadata. GMGN output follows the documented bulk-import fields: address, name, and emoji. Because GMGN does not document a wallet-group field in bulk import, group names are preserved as a searchable [GROUP] prefix by default and in grouped downloads.

BasedBot plain-text imports keep group context in the label. Portable grouped packs retain original names, emojis, and groups without flattening. Invalid input blocks copying so no wallet is silently dropped. Duplicate addresses are kept and flagged. Fomo support is coming soon.
