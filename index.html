About formats & what’s preserved +

Addresses, names, and leading emojis are preserved. BasedBot uses one address per line; GMGN uses a JSON array. BasedBot group text stays in the label because plain text does not reliably separate names from groups. GMGN groups are appended to the BasedBot label. Alert settings do not transfer to BasedBot. GMGN output uses the name, emoji and groups import fields shown in the supplied reference.

Use wallets from the same chain as the destination tracker. Invalid input blocks copying so no wallet is silently dropped. Duplicate addresses are kept and flagged. Fomo support is coming soon.
